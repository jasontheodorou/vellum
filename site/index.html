Vellum

A terminal window that works with you, not against you.

Vellum is a simple upgrade to the macOS Terminal for Claude Code. It is easy on the eyes, it remembers what you decide, and it keeps your projects apart.

01

Easy on the eyes

Soft lemon paper, charcoal ink and the Paper Mono typeface, set large enough to read in comfort.

Every colour Claude Code uses is readable on the page, so nothing hides in pale text.

02

A journal that is always on

While you work, Vellum notes what you decide and why. When you finish, it sorts the notes into decisions, lessons and what to do next.

Ask what did we decide about the header? and Claude finds it, in your own words.

03

Projects kept apart

Each project gets its own shape and colour at the bottom of the window, so you can tell windows apart at a glance.

Each one also gets its own localhost port, so two projects never fight over the same address.

Install

You need a Mac and Claude Code. Paste this line into Terminal and press Enter.

curl -fsSL https://raw.githubusercontent.com/jasontheodorou/vellum/main/install.sh | bash
