# .scribe/

Terminal Scribe keeps this project's journal here. The folder is excluded from
git on this computer only (in .git/info/exclude), so it is never committed or
shared unless you choose to.

- `logbook/YYYY-MM-DD.md`: a running account of each day's sessions
- `decisions/NNN-slug.md`: decisions, with the reasons for them
- `experiments/YYYY-MM-DD-slug.md`: things tried, and what happened
- `lessons.md`: lessons worth keeping
- `glossary.md`: words with a special meaning in this project (added when needed)

You do not need to open these files. Ask Claude, for example "what did we
decide about the navigation?"
