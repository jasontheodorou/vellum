# .vellum/

Vellum keeps this project's journal here. The folder is excluded from
git on this computer only (in .git/info/exclude), so it is never committed or
shared unless you choose to.

- `overview.md`: where the project stands today, on one screen
- `INDEX.md`: every entry with a one-line summary (rebuilt automatically)
- `logbook/YYYY-MM-DD.md`: an account of each day's sessions
- `decisions/NNN-slug.md`: decisions, the options turned down and the reasons
- `experiments/YYYY-MM-DD-slug.md`: things tried, and what happened
- `lessons.md`: lessons worth reusing, grouped by topic
- `preferences.md`: what you like and reject, in your own words
- `glossary.md`: words with a special meaning in this project
- `weekly/YYYY-Www.md`: a round-up of each week
- `artefacts/`: snapshots worth keeping, such as a design before it was replaced

You do not need to open these files. Ask Claude, for example "what did we
decide about the navigation?"
