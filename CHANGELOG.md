# Changelog

This project uses [semantic versioning](https://semver.org). The version lives in `.claude-plugin/plugin.json`.

## 0.10.0 beta (unreleased)

The first public release.

- `install.sh`: one Terminal command installs the Terminal theme, the plugin and the status line, and ends with a welcome screen. It backs up Claude Code's settings first and is safe to run again.
- A Terminal profile with sunny yellow paper, charcoal ink and Paper Mono at 18 point, with every text colour readable. `vellum theme undo` goes back to your previous profile.
- A journal for every project, kept by Claude as you work and organised by a curator when each session ends.
- Projects in plain English: start, open, list, rename, close, reopen and archive them. Each gets a folder, git, a README, a journal and a port.
- Recall: search every past Claude Code conversation on your Mac.
- A quiet status line that shows each project's name in its own colour and shape.
- A one-line recap of last time when you come back after a break.
- Checks before pushing code, and publishing to GitHub.
