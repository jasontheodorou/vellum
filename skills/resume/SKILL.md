Run `"${CLAUDE_PLUGIN_ROOT}/bin/vellum" resume` from the project root. After resuming, it prints the journal instructions and the journal for this project. Follow those instructions for the rest of this session, and use the journal it printed to answer questions about the project.

Then tell them: "Journaling is back on."
